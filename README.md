# Claude 娘桌宠 · claude-desk-pet

一个给 [Claude Code](https://claude.com/claude-code) 用的小插件：Claude 干活的时候，桌面上会有一个 Q 版 Claude 娘陪着你，实时显示它在做什么。

![六种状态预览](docs/preview.png)

## 功能

**🧡 桌宠悬浮窗**：透明背景，默认坐在你当前窗口的顶边上陪你

| Claude 在做什么 | 桌宠的样子 |
|---|---|
| 思考中 | 闭眼想事情，"思考中…" |
| 跑命令、改文件 | 敲键盘，气泡里显示正在改哪个文件 |
| 读文件、搜索、上网查 | 捧着书记笔记 |
| 回复完，等你说话 | 敲几秒门："轮到你啦！"，然后安静地坐着等你 |
| 派小助手（子代理）干活 | "小助手在读 xx"、"小助手×3 在改 xx"，说小助手们正在干什么 |
| 这一轮以出错结束 | 慌张冒汗 |
| 某个命令失败了 | 皱一下眉（Claude 一般会自己想办法），然后接着想 |
| 被你打断 | 心虚 |
| 干了 3 分钟以上的大活 | 撒花庆祝 🎉 |
| 等你超过 10 分钟 | 打瞌睡，头顶飘 z Z |

还有一个彩蛋：连续失败 3 次会……石化 🗿

- **坐在窗口上**：你切到哪个窗口，她就跳到哪个窗口的顶边上坐着；窗口拖走她跟着走，窗口关了、最小化了她就掉下去。窗口最大化、上面放不下时，她坐在屏幕底边
- 坐着的时候会偶尔晃晃腿；干活时盘腿看着，敲键盘时抱着键盘；站起来、坐下去会有过渡动作
- 被其他窗口挡住时她也跟着被挡住（提醒休息、说话的时候除外）
- **拖动**她到别处松手，她会掉下去，落在下面第一个窗口（或屏幕底边）上，并且就待在那儿，不再自动跟着窗口跳；右键勾上「自动跟着当前窗口」或者 `/pet home` 就恢复
- 不想让她坐窗口，右键取消「坐在窗口上」，她就固定在一个位置、永远置顶，可以拖到屏幕任何位置
- **单击**她：戳一下，她会有反应；连着戳会生气哦
- 鼠标在她**头上来回划**：摸头，她会害羞
- 她偶尔会主动说话：早上问好、饭点提醒吃饭、平时随口聊两句（右键菜单可以关掉「闲聊」）
- **同时开着好几个会话**时：
  - 她跟着你最近发过消息的那个会话，几个会话同时在忙也不会来回换
  - 别的会话干完了、出错了，或者新开了一个会话，她会插播 10 秒（响提示音、敲门），然后回来
  - 你这个会话干完了而别的会话还在忙，她就换去陪忙着的那个
  - 气泡多一行小字，说别的会话怎么样了，比如"it-tools｜PicGO 在等你、2 个在忙"（竖线前面是她正在跟的会话）。气泡会跟着文字变宽，靠近屏幕边时往里挪
  - 后台还有小助手在干活时，"轮到你啦"后面会带一句"小助手还在后台"
- 敲键盘的时候会眨眼，偶尔连眨两下
- **拖动**她：被拎起来时手脚垂着；甩得快，身体会往反方向歪
- 你在她所在的屏幕上全屏看视频、打游戏、放 PPT 时，她会自动躲起来，退出全屏再回来
- **双击**桌宠：把 Claude 窗口叫到前台
- **右键**菜单：调大小（小/中/大）、坐在窗口上、自动跟着当前窗口、切到 Claude 时自动隐藏、提示音开关、闲聊开关、状态栏语言、休息提醒、退出

**⏰ 休息提醒**：连续工作到点了，她会提醒你休息；不理她，就越催越急

| 阶段 | 什么时候 | 她的样子 |
|---|---|---|
| 温柔 | 连续使用 50 分钟 | 端着茶杯挥手 |
| 催促 | 再过 10 分钟没理 | 双手合十求你 |
| 急了 | 再过 10 分钟没理 | 叉腰鼓腮跺脚，之后每 5 分钟再催一次 |

- 按键盘鼠标有没有动来算"在工作"，离开电脑超过 5 分钟就当你休息过了，自动重新计时
- 提醒的时候**点她一下**，或右键选「我去休息了」，就重新计时
- 晚上 23 点到凌晨 5 点，台词会变成催你睡觉
- 全屏的时候到点了，会等你退出全屏再提醒
- 右键菜单里可以开关、选间隔（30 / 45 / 50 / 60 / 90 分钟），还有「试一下提醒」不用等就能预览
- 想细调，改 `~/.claude/desk-pet/settings.json`：`breakWork`、`breakEscalate`、`breakRepeat`、`breakAway`（单位都是分钟），`breakEnabled`（true / false）

**📊 Token 状态栏**：输入框下方常驻一行用量信息

> 当前会话 输入 12.3k · 输出 4.1k · 缓存命中 87% · 上下文 31% · 5h额度 23%

英文版：

> Session Input 12.3k · Output 4.1k · Cache hit 87% · Context 31% · 5h Limit 23%

默认跟随系统语言，也可以在桌宠右键菜单的「状态栏语言 / Language」里切换

**🔔 提示音**（右键菜单可以关掉）

| 什么时候 | 声音 |
|---|---|
| Claude 回复完（包括 3 分钟以上的大活撒花） | 钢琴"叮咚" |
| 这一轮以出错结束 | 复古 RPG"哔哔" |
| 休息提醒：温柔、催促 | 钢琴"叮咚" |
| 休息提醒：急了（之后每 5 分钟再催时也响） | 复古 RPG"哔哔" |

工具调用出错、石化、被打断、摸头戳她、闲聊都没有声音

**命令**

- `/token-stats`：查看本会话和本项目累计的 token 用量、缓存命中率、额度
- `/pet`：召唤桌宠（不小心关掉、藏起来了都能叫回来）；后面还能跟子命令，`/pet help` 看全部：
  - `/pet hide` 藏起来；`/pet home` 回到当前窗口并重新跟着窗口（不坐窗口时回到屏幕右下角）
  - `/pet roam on|off` 坐在窗口上，`/pet follow on|off` 自动跟着当前窗口
  - `/pet size small|medium|large` 调大小
  - `/pet sound|chat on|off` 开关提示音、闲聊
  - `/pet break on|off|30|45|50|60|90` 休息提醒开关和间隔，`/pet break test` 试一下，`/pet rest` 我去休息了
  - `/pet quit` 退出

## 运行要求

> 🍎 **macOS 用户**：这个仓库目前只支持 Windows，请使用 [wangmeng003](https://github.com/wangmeng003) 维护的 Mac 移植版：[claude-desk-pet-mac](https://github.com/wangmeng003/claude-desk-pet-mac)

- **Windows**（悬浮窗和提示音用的是 Windows 的接口）
- **Python 3**，并且在命令行里输入 `python` 能直接运行
- **Pillow** 图像库，用下面这条命令安装：

```bash
pip install pillow
```

## 安装

**在终端里的 Claude Code**，输入：

```
/plugin install Desk-Pet --marketplace WILSONowo/claude-desk-pet
```

然后按 `y` 添加插件市场，选择 user（用户）范围，按回车确认。

**也可以在命令行里运行：**

```bash
claude plugin install Desk-Pet --marketplace WILSONowo/claude-desk-pet
```

**在 Claude 桌面端**：点输入框旁边的 **+** → **Plugins** → **Add marketplace**，填入 `WILSONowo/claude-desk-pet`，再点 **Add plugin**。

装好后，新开一个会话，桌宠就会出现在屏幕右下角。

## 自定义

- **换立绘**：把 `pet/sprites/` 里的 PNG 换成你自己的图（透明背景，文件名保持不变）。半透明的边缘、发丝、阴影都会照原样显示，不需要另外描边
- **换眨眼**：用 `python tools/blink_patch.py export typing` 导出绿底原图，让 AI 只把眼睛改成闭眼，再用 `python tools/blink_patch.py build typing <改好的图>` 生成补丁
- **换提示音**：替换 `sounds/done.wav`（完成）和 `sounds/error.wav`（出错）
- **改台词**：Claude 状态的气泡文字写在 `hooks/register.ts` 里；闲聊、摸头、戳她的台词写在 `pet/lines.json` 里

桌宠的位置、大小、开关（`roam` 坐在窗口上、`follow` 跟着当前窗口等）和状态栏语言（`lang`：`zh` / `en` / `auto`）保存在 `~/.claude/desk-pet/settings.json`。
